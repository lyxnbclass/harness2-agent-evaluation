## Bad Case / 调试证据
- `dev-08`：`outcome=resolved`、最终回答 `5`，但 Trace 的第二条消息是 `uppercase(text="5")`，该题只允许 `add`；首次偏离在 assistant tool_call，不在 Tool Result。Toy Runtime 的全局工具 Schema 允许 `uppercase`，案例权限只被 Stage 02 指标观察，尚未强制拦截。
- `val-04`：`add(2,2)` 返回 `4`，FakeModel 最终回答 `5`，契约判为 `failed`；首次可见结果偏离在最终回答。真实原因是预设脚本给出了错误 final，不能归咎于未验证的真实模型。

- 第 1–4 题要点正确；第 5 题需纠正 replay 与 rerun：前者只按 `run_id` 展示已保存的同一次事件，后者是新运行，可能因模型随机性、外部工具状态、依赖或版本变化而不同。用户尚未明确确认理解本轮新增代码。保留 Stage 01 Runtime 与官方 substrate 边界、Stage 02 分母代码未独立解释的记录。
