## 真实实验与运行命令
- OBSERVED：Windows 已安装 Python 3.12.13 下执行 `python -m unittest discover -s experiments/toy_agent -p test_runtime.py -v`，退出 0，6 项测试 `OK`（0.156s）。覆盖工具结果回传、三工具与闭合 Schema、未知工具、实际超时、依赖失败与 `max_steps`/非法模型输出。未运行真实模型。
- OBSERVED：`python -m experiments.toy_agent.demo` 退出 0；`reports/stage01_toy_agent_demo.json` 记录输入 `Add 2 and 3`，`add(a=2,b=3)`，工具返回 `5`，最终回答 `The sum is 5`，状态 `completed`。命令由本机 Python 3.12 执行，无网络或付费调用。

## Bad Case / 调试证据
- OBSERVED：测试对 `delay(seconds=1)` 设置 `tool_timeout=0.01`，子进程超时被转换为 `tool_timeout`，轨迹最后一项为工具错误，无最终答案。未知工具 `delete_all` 返回 `unknown_tool`，不会执行；`add(a=True,b=3)` 与额外 `debug` 字段返回 `invalid_args`。这些失败由项目自研单测验证，不是官方 Benchmark 失败。
